## 🔴 重要度：高

### 1. Supabase（クラウド）接続の実地テストが未実施
- **状況**：ローカルSQLiteでは全テスト合格。Supabase接続は実アカウントが必要なため未検証。
- **リスク**：本番（Vercel + Supabase）で、集計値の型違いなど細かな差異が出る可能性。
  - 対策として、件数や工数の集計は `Number()` で数値に揃える処理を入れ済み。
- **今後**：実際にSupabaseを作って一度デプロイし、登録〜タスク追加まで通しで確認する。

### 2. 本番のセキュリティ設定（JWT_SECRET）
- **状況**：`JWT_SECRET` が未設定だと、コード内の仮の文字列が使われる。
- **リスク**：本番でそのままだと、ログイン情報の安全性が下がる。
- **今後**：Vercelの環境変数に、必ずランダムな `JWT_SECRET` を設定する
  （`openssl rand -base64 32` で生成）。`.env.example` に記載済み。

### 3. PWAアイコン画像が未作成
- **状況**：`manifest.ts` が `icon-192.png` / `icon-512.png` を参照しているが、画像ファイルはまだ無い。
- **リスク**：ホーム画面に追加したとき、アイコンが既定の見た目になる。
- **今後**：白黒のシンプルなアイコン（192px / 512px）を作って各アプリの `public/` に置く。

## 🟡 重要度：中

### 4. WBSアプリに自動テストが無い
- **状況**：ToDoアプリには13件の自動テストがあるが、WBSアプリは手動確認のみ。
- **今後**：WBSにも Playwright テスト（プロジェクト作成→タスク追加→完了）を追加する。

### 5. クエストログと本体リストの同期
- **状況**：左上のクエストログは独自にデータを取得するため、本体のリストで完了しても
  クエストログは「ウィンドウを再度クリックしたとき」に更新される。
- **リスク**：一瞬だけ表示がズレることがある（致命的ではない）。
- **今後**：状態を共有して即時反映するように改善できる。

### 6. better-sqlite3 のインストール（ローカル）
- **状況**：ローカルSQLiteは `better-sqlite3` という部品を使う。これはパソコンに合わせて
  自動でビルドされる（通常は問題なし）。
- **リスク**：稀に、Mac は「Xcodeコマンドラインツール」、Windows は「ビルドツール」が必要になる。
  - Mac：`xcode-select --install`
  - Windows：Node.jsインストール時の「Tools for Native Modules」にチェック（手順書に記載済み）
- **今後**：もし `npm install` でエラーが出たら、この点を確認する。

## 🟢 重要度：低（今後やりたい）

### 7. Capacitor の URL 設定
- iOSアプリ化する前に、`capacitor.config.ts` の `server.url` を
  ローカル（localhost）から、Vercelの公開URLに変える必要がある。手順書に記載済み。

### 8. Android 対応
- Capacitor は Android にも対応可能。`npx cap add android` で展開できる（未着手）。

### 9. データのバックアップ
- ローカルSQLiteのデータは各アプリの `.data/` フォルダにある。
  クラウド（Supabase）に移行すれば自動でバックアップされる。
