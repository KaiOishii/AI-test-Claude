# プロンプトの基礎

## はじめに

プロンプトとは、AIに対して送る指示や質問のことです。うまく書けるようになると、AIがぐっと使いやすくなります。この記事では、より良い返答をもらうためのコツを、基本からやさしく紹介していきます。

---

## 1. プロンプトって何だろう？

プロンプト（Prompt）は、AIへの「話しかけ方」のことです。日常会話と同じで、伝え方ひとつで相手の反応がガラッと変わります。

- **シンプルな例**: 「東京の天気は？」
- **もう少し具体的な例**: 「マーケティング担当者向けに、SNS戦略の提案書を日本語で400字以内で作ってください」

どちらが良い・悪いということはなく、**目的に合った伝え方**ができると、ぐっと使いやすくなります。

---

## 2. 良いプロンプトの3つのポイント

### 2-1. 具体的に伝える（Clarity）

ふわっとした表現より、具体的な言葉の方が伝わりやすいです。

| こんな感じだと… | こう書くともっと良い |
|--------|--------|
| 「何か書いて」 | 「新入社員向けの歓迎メールを書いてください」 |
| 「要約して」 | 「以下の文章を3行以内で要約してください」 |

### 2-2. 背景を教えてあげる（Context）

「なぜ聞いているのか」「どんな状況なのか」を添えてあげると、回答の的確さがぐんと上がります。

```
もったいない例: 「改善策を教えて」

こうするともっと良い: 「私はECサイトを運営しています。
直近3ヶ月でカート放棄率が15%上昇しました。
考えられる原因と、できれば対策も教えてもらえますか？」
```

### 2-3. 形式を指定してみる（Constraints）

「どんな形で答えてほしいか」を伝えると、使いやすい回答が返ってきます。

- 「箇条書きで5つ挙げてください」
- 「専門用語を使わず、中学生にも伝わる言葉でお願いします」
- 「200字以内でまとめてください」

---

## 3. プロンプトのよくあるパターン

### 3-1. 役割をお願いする（Role Prompting）

「〇〇として答えてください」と役割を伝えると、専門的な視点からの回答が得やすくなります。

```
あなたは10年のキャリアを持つUXデザイナーです。
このウェブサイトの使いにくい点を教えてもらえますか？
```

### 3-2. 例を見せる（Few-Shot Prompting）

「こういう感じで書いてほしい」という例を一緒に渡すと、意図が伝わりやすくなります。

```
以下のフォーマットで商品説明を書いてください。

例:
商品名: コーヒーメーカー
説明: 毎朝の一杯をより豊かに。本格的なエスプレッソが自宅で楽しめます。

商品名: ワイヤレスイヤホン
説明:
```

### 3-3. 順を追って考えてもらう（Chain of Thought）

難しい問題は「ステップごとに」とお願いすると、丁寧に答えてもらいやすくなります。

```
以下の問題を、ステップごとに考えながら解いてください。
各ステップで何をしているかも書いてもらえると助かります。

問題: ...
```

### 3-4. 出力の形式を指定する

```
以下の内容をJSON形式で出力してください:
- name: 名前
- age: 年齢
- skills: スキルのリスト
```

## 4. やりがちな失敗と、うまくいくコツ

### 失敗その1: 指示があいまいすぎる

```
❌ 「ブログを書いて」
✅ 「30代向けの健康ブログの記事を書いてください。
   テーマは『睡眠の質を上げる5つの習慣』で、
   見出しを含めて800字くらいでお願いします。」
```

### 失敗その2: 一度に頼みすぎてしまう

```
❌ 「要約して、翻訳して、箇条書きにして、タイトルも考えて」

✅ まずは要約をお願いして、次に翻訳、というように
   少しずつ分けてお願いする方がうまくいきます。
```

### 失敗その3: 「〜しないで」と否定形で伝える

```
❌ 「難しい言葉を使わないで」
✅ 「小学生でも分かるような、やさしい言葉でお願いします」
```

否定形より肯定形の方が、AIには伝わりやすいことが多いです。

---

## 5. もっと上手に使うために

### 少しずつ改善してみよう

プロンプトは一発で完璧にしなくて大丈夫です。「ちょっと違うな」と思ったら、少し言い方を変えて試してみましょう。

1. まずそのまま送ってみる
2. 返ってきた回答を見て、足りないところを確認する
3. 伝え方を少し工夫して、もう一度送ってみる
4. 少しずつ良くなっていきます

### テンプレートを手元に置いておく

よく使うプロンプトは、メモしておくと便利です。

```
## [やってほしいこと]のテンプレート

役割: あなたは[役割]です。
背景: [状況や文脈]
お願い: [具体的にやってほしいこと]
条件:
- [条件1]
- [条件2]
出力の形式: [どんな形で返してほしいか]
```

---

## 6. ちょっと応用的な話

### システムプロンプトとユーザープロンプト

AIとのやり取りには、大きく2種類のプロンプトがあります。

- **システムプロンプト**: AIの動き方全体を設定する、いわば「最初のルール決め」
- **ユーザープロンプト**: 会話の中で都度送る、普段の質問や指示

### 会話を重ねて深めていく

一度のやり取りで全部解決しようとせず、対話を続ける中で答えを磨いていくのも良い方法です。

```
1回目: 「〇〇についてのアイデアを5つ提案してください」
2回目: 「3番目のアイデアについて、もう少し詳しく教えてもらえますか？」
3回目: 「それを実際にやってみるための手順を教えてください」
```

---

## まとめ

良いプロンプトのコツは、シンプルに言うとこの5つです。

1. **具体的に**伝える
2. **背景・文脈**を添える
3. **形式**（長さ・スタイル）を指定する
4. **役割**をお願いする
5. **試しながら**少しずつ改善する

プロンプトは、慣れれば慣れるほど上手になります。完璧を目指さず、気軽に試してみてください。小さな工夫の積み重ねが、AIとのやり取りをどんどん楽しくしてくれますよ。

---

*プロンプトエンジニアリングは日々進化している分野なので、気になったことはどんどん試してみるのが一番の近道です。*
