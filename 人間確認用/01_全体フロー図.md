## 1. はじめての導入フロー（PC）

```mermaid
flowchart TD
    A[パソコンを用意] --> B{Mac or Windows?}
    B -->|Mac| C[環境構築手順書 Mac版]
```

## 2. アプリの仕組み（全体構成）

```mermaid
flowchart LR
    subgraph ブラウザ[🌐 ブラウザ / iPhone]
      UI[画面 React]
    end
    subgraph サーバー[⚙️ Next.js サーバー ポート3000]
      TODOS[/todos ToDoリスト]
      WBS[/dashboard WBS管理]
      API[APIルート]
      AUTH[ログイン認証 JWT]
    end
    subgraph データ[🗄 データベース]
      SQLITE[(ローカル SQLite app.db)]
      SUPA[(クラウド Supabase)]
    end

    UI -->|操作| API
    API --> AUTH
    API -->|DATABASE_URL なし| SQLITE
    API -->|DATABASE_URL あり| SUPA
```

> **ポイント：** ToDoとWBSは**同じアプリ**（ポート3000）で動きます。
> 設定（DATABASE_URL）の有無でDBを自動切り替えします。

## 3. データベース切り替えの判定

```mermaid
flowchart TD
    START[アプリ起動] --> CHECK{DATABASE_URL が設定されている?}
    CHECK -->|いいえ| SQLITE[ローカルSQLiteを使用<br/>設定不要・すぐ動く・テスト向き]
    CHECK -->|はい| SUPA[クラウドSupabaseを使用<br/>iPhoneとPCでデータ同期]
    SQLITE --> RUN[アプリが動く]
    SUPA --> RUN
```

## 4. ログインの流れ

```mermaid
sequenceDiagram
    participant U as ユーザー
    participant A as アプリ
    participant D as データベース
    U->>A: メール+パスワードで登録/ログイン
    A->>D: ユーザー情報を確認
    D-->>A: OK
    A->>A: パスワードを暗号化(bcrypt)して照合
    A-->>U: ログイン成功（JWTをCookieに保存）
    U->>A: 以降の操作（タスク追加など）
    A->>A: Cookieのトークンで本人確認
```
