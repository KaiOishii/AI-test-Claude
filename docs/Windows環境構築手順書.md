# 【Windows】環境構築手順書
## アプリを動かすための準備

---

> この手順書は **Windows パソコンを使っている方向け** です。
> プログラミング未経験でも迷わず進められるように書きました。
> 上から順番に進めてください。

---

## 全体の流れ

```
① Node.js をインストール
      ↓
② Git をインストール
      ↓
③ アプリのファイルをダウンロード
      ↓
④ インストーラーを実行
      ↓
⑤ 完了！アプリ起動へ
```

---

## ① Node.js をインストール

**Node.js** とは、アプリを動かすために必要なソフトウェアです。

1. ブラウザで https://nodejs.org/ja を開く
2. **「LTS」** と書かれた左側のボタンをクリック（推奨版）
3. ダウンロードされた `node-vXX.X.X-x64.msi` をダブルクリック
4. インストーラーが開いたら、基本的に **「Next」** を押し続ける
   - 「Automatically install the necessary tools...」のチェックは **付けたまま** でOK
5. 「Install」→「Finish」で完了

### インストール確認

1. スタートメニューで **「cmd」** と入力 → **コマンドプロンプト** を開く
2. 以下を入力して Enter：

```
node -v
```

`v20.x.x` のように表示されれば成功です。

```
npm -v
```

`10.x.x` のように表示されれば成功です。

---

## ② Git をインストール

**Git** とは、アプリのファイルをダウンロードするために必要なツールです。

1. ブラウザで https://git-scm.com/download/win を開く
2. **「64-bit Git for Windows Setup」** をクリックしてダウンロード
3. ダウンロードした `.exe` をダブルクリック
4. すべて **「Next」** を押し続けて「Install」→「Finish」

### インストール確認

コマンドプロンプトで：

```
git --version
```

`git version 2.x.x` のように表示されれば成功です。

---

## ③ アプリのファイルをダウンロード

### ダウンロード先に移動

コマンドプロンプトで（自分の書類フォルダに置く例）：

```
cd %USERPROFILE%\Documents
```

### ファイルをダウンロード（クローン）

```
git clone https://github.com/KaiOishii/AI-test-Claude.git
```

完了すると `AI-test-Claude` というフォルダが作られます。

---

## ④ インストーラーを実行

1. エクスプローラーで `Documents\AI-test-Claude\インストーラー\Windows` を開く
2. **`インストール.bat`** をダブルクリック
3. 画面の案内に従って、**1（ToDo）・2（WBS）・3（両方）** を選ぶ
4. 「インストールが完了しました！」と出れば成功

> ⚠️ 「WindowsによってPCが保護されました」と出たら
> → 「詳細情報」→「実行」をクリックしてください（自分で用意したファイルなので安全です）

---

## ⑤ 完了！

これで準備は完了です。

アプリを起動するには：
- **ToDoリスト** → `インストーラー\Windows\ToDo起動.bat` をダブルクリック
- **WBS管理** → `インストーラー\Windows\WBS起動.bat` をダブルクリック

詳しくは **「【Windows】アプリ起動手順書.md」**（※同フォルダ）も参照してください。

---

## ❓ うまくいかないときは

| 症状 | 対処 |
|---|---|
| `node は認識されていません` | パソコンを再起動してから再実行 |
| `.bat` を開くと一瞬で閉じる | 右クリック →「編集」ではなく「開く」を選択 |
| 「保護されました」と出る | 「詳細情報」→「実行」を選ぶ |
| npm install がエラー | ネット接続を確認し、もう一度実行 |
