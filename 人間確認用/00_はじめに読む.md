# 👀 はじめに読む（人間が確認する用）

このフォルダは、**プログラムが分からない人でも、いま何があって・どう動くのかを
ひと目で確認できる**ようにまとめた資料です。

---

## このプロジェクトには何がある？

```
AI-test-Claude/
├── app/             … 統合アプリ（ToDo + WBS を一つに統合）
├── lib/             … DB・認証・型定義の共通ライブラリ
├── docs/            … 手順書・ガイド類
├── インストーラー/   … 簡単インストール用ツール（Mac/Windows）
├── supabase/        … クラウド公開・App Store用の設定
├── 人間確認用/       … ★このフォルダ（資料置き場）
└── tests/           … 自動テスト（Playwright）
```

---

## 2つの機能の違い（かんたんに）

| | 🗒 ToDoリスト | 📊 WBS管理 |
|---|---|---|
| 何をする？ | 「やること」をメモ・チェック | プロジェクトをタスクに分けて進捗管理 |
| 主な機能 | 追加/完了/検索/カテゴリ/カレンダー/通知 | プロジェクト/階層タスク/工数/進捗/今日のタスク |
| 向いている人 | 個人の日々のタスク管理 | チームや大きな作業の計画・管理 |
| 起動アドレス | http://localhost:3000/todos | http://localhost:3000/dashboard |

どちらも **同じアプリ（ポート 3000）** で動きます。白黒のシンプルなデザインで統一しています。

---

## ✨ ゲーム化機能：クエストログ

両機能の **画面左上** に「⚔ クエスト」という小さなボタンが出ます。
クリックすると、**今日やるべきタスクが「クエスト」として一覧表示**されます。

- ✅ クエストを完了するとチェックアニメ＋進捗バーが進む
- 🏆 全部終わると「全クエストクリア！」の達成演出
- 🔥 毎日続けると「連続達成日数（ストリーク）」が増える
