# アプリ起動手順書
## ToDoリスト・WBS管理アプリを動かす（Mac）

---

> **この手順書を使う前に**
> `docs/Mac環境構築手順書.md` が完了していることを確認してください。

---

## ⚡ かんたん起動（おすすめ）

コマンド入力が苦手な方は、こちらが一番かんたんです。

1. `インストーラー/Mac/インストール.command` をダブルクリック
2. 完了したら `ToDo起動.command` または `WBS起動.command` をダブルクリック
3. ブラウザが自動で開きます 🎉

> ⚠️ **「開いていません」と出る場合（macOS セキュリティ）**
>
> ターミナルで以下を実行してから、もう一度ダブルクリックしてください：
> ```bash
> xattr -rd com.apple.quarantine ~/AI-test-Claude/インストーラー/
> ```
> または：ファイルを **右クリック →「開く」→「開く」** を選択。

## 🎮 クエストログ（ゲーム化）

ログイン後、画面の **左上に「⚔ クエスト」ボタン** が出ます。
クリックすると、今日やるべきタスクがクエストとして並びます。
チェックすると進捗バーが進み、全部終わると達成演出が出ます（🔥連続日数も記録）。

## ターミナルで起動する方法

### ① アプリのフォルダに移動

```bash
cd ~/AI-test-Claude
```

### ② 初回のみ：パッケージをインストール

```bash
npm install
```

1〜3分かかります。完了まで待ちましょう。

> ⚠️ 2回目以降はこの手順は不要です。

### ③ アプリを起動

```bash
npm run dev
```

以下のように表示されれば起動成功です：

```
▲ Next.js 16.x.x (Turbopack)
- Local:   http://localhost:3000
✓ Ready in xxxms
```

> ⚠️ **このターミナルは閉じないでください。**
> 閉じるとアプリも止まります。
> 止めたいときは `Control + C` を押します。

### ④ ブラウザで開く

| アプリ | URL |
|---|---|
| **ホーム**（アプリ選択） | http://localhost:3000/ |
| **ToDoリスト** | http://localhost:3000/todos |
| **WBS管理** | http://localhost:3000/dashboard |

どちらも同じサーバーで動きます。

## アカウントを作る（初回のみ）

1. ブラウザでいずれかのURLを開く
2. 「**新規登録**」をクリック
3. 名前・メールアドレス・パスワードを入力 → 「登録する」
4. アプリ画面に移動すれば成功

## ToDoリストの使い方

| 操作 | やり方 |
|---|---|
| **追加** | 右上の「+ 追加」ボタン |
| **完了** | タスク左端の □ をクリック |
| **編集** | タスクにマウスを合わせ「編集」 |
| **削除** | タスクにマウスを合わせ「削除」 |
| **検索** | 画面上部の検索欄 |
| **フィルター** | 左サイドバーで絞り込み |
| **カテゴリ** | 左サイドバー「カテゴリ」横の + |
| **ダークモード** | 右上の ☾ ボタン |
| **カレンダー** | 左サイドバー「カレンダー」 |

## WBS管理の使い方

### プロジェクトを作る

1. 左サイドバーの「**プロジェクト**」をクリック
2. 右上の「**+ 新規**」をクリック
3. プロジェクト名・終了予定日・ステータスを入力 → 「追加」

### タスクを追加する

1. プロジェクトをクリックして詳細画面へ
2. 「**+ タスク追加**」をクリック
3. タスク名・優先度・予定工数を入力 → 「追加」

### 子タスクを追加する（階層構造）

1. タスクにマウスを合わせ右端の「**＋**」をクリック
2. 子タスク名を入力 → 追加

### 今日のタスクに追加する（クエストログ連携）

1. タスクにマウスを合わせ右端の「**☑**」アイコンをクリック
2. 左サイドバー「**今日のタスク**」に表示される

## よくある質問

### Q. アプリを止めたい

アプリが動いているターミナルで `Control + C` を押す。

### Q. データをリセットして最初からやり直したい

アプリを止めてから：

```bash
rm -rf ~/AI-test-Claude/.data
```

次回起動時に自動で作り直されます。

### Q. ログインできない

- パスワードは6文字以上必要です
- メールアドレスの入力ミスがないか確認
- それでもダメなら上の「データをリセット」を試してください

### Q. ブラウザを開いても「このサイトにアクセスできません」と出る

ターミナルで `npm run dev` が動いているか確認してください。
止まっていたら再度 `npm run dev` を実行します。
