# 【Mac】環境構築手順書
## アプリを動かすための準備

---

> この手順書は **MacBook を使っている方向け** です。
> プログラミング未経験でも迷わず進められるように書きました。
> 上から順番に進めてください。

---

## 全体の流れ

```
① ターミナルを開く
      ↓
② Homebrew をインストール
      ↓
③ Node.js をインストール
      ↓
④ Git をインストール
      ↓
⑤ アプリのファイルをダウンロード
      ↓
⑥ 完了！アプリ起動手順書へ
```

---

## ① ターミナルを開く

**ターミナル**とは、キーボードで文字を入力してMacに命令を出す黒い画面です。

### 開き方

1. キーボードの **`Command ⌘`** と **`スペース`** を同時に押す
2. 画面上部に検索バーが出る（Spotlight 検索）
3. **`ターミナル`** と入力して **`Enter`** を押す
4. 黒い（または白い）画面が開けばOK

> 以降、この手順書に出てくる `このような文字` はターミナルに入力するコマンドです。
> コピー&ペーストして使えます。

---

## ② Homebrew をインストール

**Homebrew** とは、Mac でソフトウェアをかんたんにインストールできる便利ツールです。

### インストール

ターミナルに以下をコピー&ペーストして **`Enter`** を押す：

```
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

### 途中で聞かれること

- **パスワードを求められたら** → MacBook のログインパスワードを入力（入力しても画面に表示されません。正常です）
- **`Press RETURN to continue` と表示されたら** → `Enter` を押す
- 5〜10分ほどかかります。待ちましょう

### インストール確認

完了後、以下を入力して Enter：

```
brew --version
```

以下のように表示されれば成功です：

```
Homebrew 4.x.x
```

> ⚠️ **「zsh: command not found: brew」と出た場合**
> ターミナルの最後のほうに `Add Homebrew to your PATH` という指示が出ているはずです。
> その下に表示されている `eval "$(...)"` で始まるコマンドをコピーして実行してください。

---

## ③ Node.js をインストール

**Node.js** とは、アプリを動かすために必要なソフトウェアです。

### インストール

```
brew install node
```

3〜5分かかります。完了まで待ちましょう。

### インストール確認

```
node -v
```

以下のように表示されれば成功です（数字は多少違っても大丈夫）：

```
v20.x.x
```

```
npm -v
```

```
10.x.x
```

2つとも表示されれば OK です。

---

## ④ Git をインストール

**Git** とは、アプリのファイルをダウンロードするために必要なツールです。

Homebrew が入っていれば以下でインストールできます：

```
brew install git
```

### インストール確認

```
git --version
```

```
git version 2.x.x
```

上記のように表示されれば成功です。

---

## ⑤ アプリのファイルをダウンロード

### ダウンロード先のフォルダを決める

まずホームフォルダ（デスクトップではなく、ユーザーのルートフォルダ）に移動します：

```
cd ~
```

### ファイルをダウンロード（クローン）

```
git clone https://github.com/KaiOishii/AI-test-Claude.git
```

完了すると `AI-test-Claude` というフォルダが作られます。

### 確認

```
ls AI-test-Claude
```

以下のファイルが表示されれば成功です：

```
README.md  todo-app  wbs-app  手順書.md  ...
```

## ❓ うまくいかないときは

| 症状 | 対処 |
|---|---|
| `command not found` と出る | ターミナルを一度閉じて開き直してから再実行 |
| Homebrew のインストールが途中で止まる | もう一度同じコマンドを実行（何度でも大丈夫）|
| パスワードを入力しても反応しない | 入力されているが表示されないだけ。そのまま Enter |
| エラーが英語でよくわからない | エラー文をそのままコピーして調べると解決策が見つかります |
