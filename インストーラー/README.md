# 📦 インストーラー

OS（パソコンの種類）ごとにフォルダを分けています。
**自分のパソコンに合うフォルダ**を開いてください。

---

## どのフォルダを使う？

| あなたの環境 | 開くフォルダ | 使うファイル |
|---|---|---|
| 🍎 **Mac** | `Mac/` | `インストール.command` |
| 🪟 **Windows** | `Windows/` | `インストール.bat` |
| 📱 **iPhone** | `iPhone/` | `iPhone導入ガイド.md` を読む |

---

## 使い方（Mac / Windows 共通の流れ）

```
① インストール（インストール.command または インストール.bat）
      ↓ ToDo / WBS / 両方 を選ぶ
② 起動（ToDo起動 / WBS起動）
      ↓
③ ブラウザでアプリが開く 🎉
```

### Mac
1. `Mac/インストール.command` をダブルクリック
2. `1`（ToDo）・`2`（WBS）・`3`（両方）から選ぶ
3. 終わったら `ToDo起動.command` または `WBS起動.command` をダブルクリック

> ⚠️ 初回は「開発元を確認できません」と出る場合があります。
> その時は **右クリック →「開く」** を選んでください。

### Windows
1. `Windows\インストール.bat` をダブルクリック
2. `1`・`2`・`3` から選ぶ
3. 終わったら `ToDo起動.bat` または `WBS起動.bat` をダブルクリック

> ⚠️ 「WindowsによってPCが保護されました」と出たら
> **「詳細情報」→「実行」** を選んでください。

### iPhone
`iPhone/iPhone導入ガイド.md` を読んでください。
（iPhone はクラウド公開後に「ホーム画面に追加」または App Store 経由で使います）

---

## 前提：先に環境構築が必要です

このインストーラーを使う前に、Node.js のインストールが必要です。
まだの場合は先に以下を実施してください：

- Mac → `【Mac】環境構築手順書.md`
- Windows → `【Windows】環境構築手順書.md`

---

## ToDo と WBS の違い

| アプリ | 用途 | ポート |
|---|---|---|
| **ToDoリスト** | 個人の「やること」管理 | http://localhost:3000 |
| **WBS管理** | プロジェクトのタスク・工数・進捗管理 | http://localhost:3001 |

両方インストールすれば、同時に動かせます。
