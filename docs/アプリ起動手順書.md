# 【Mac】アプリ起動手順書
## ToDoアプリ・WBS管理アプリを動かす

---

> **この手順書を使う前に**
> 「【Mac】環境構築手順書.md」が完了していることを確認してください。

---

## ⚡ かんたん起動（インストーラー版・おすすめ）

コマンド入力が苦手な方は、こちらが一番かんたんです。

1. `インストーラー/Mac/インストール.command` をダブルクリック
   → `1`（ToDo）・`2`（WBS）・`3`（両方）から選んでインストール
2. `インストーラー/Mac/ToDo起動.command`（または `WBS起動.command`）をダブルクリック
   → ブラウザが自動で開きます 🎉

> 「開発元を確認できません」と出たら、**右クリック →「開く」** を選んでください。

下の手順は、仕組みを理解しながら手動で進めたい方向けの詳しい版です。

---

## 🎮 新機能：クエストログ（ゲーム化）

ログイン後、画面の **左上に「⚔ クエスト」ボタン** が出ます。
クリックすると、今日やるべきタスクが「クエスト」として並びます。
チェックすると進捗バーが進み、全部終わると達成演出が出ます（🔥連続日数も記録）。
ToDo・WBS どちらにもあります。

---

## 全体の流れ

```
① ターミナルを開く
      ↓
② ToDoアプリを起動する
      ↓
③ ToDoアプリを操作してみる
      ↓
④ WBS管理アプリを起動する
      ↓
⑤ WBS管理アプリを操作してみる
```

---

# ToDoアプリ

---

## ① ターミナルを開く

`Command ⌘ + スペース` → `ターミナル` と入力 → `Enter`

---

## ② todo-app フォルダに移動する

```
cd ~/AI-test-Claude/todo-app
```

> `cd` は「このフォルダに入る」という命令です。

---

## ③ 必要なファイルをインストールする（初回のみ）

```
npm install
```

1〜3分かかります。最後に `added xxx packages` と表示されれば完了です。

> ⚠️ 2回目以降はこの手順は不要です。

---

## ④ アプリを起動する

```
npm run dev
```

以下のように表示されれば起動成功です：

```
▲ Next.js 16.x.x
- Local:   http://localhost:3000
- ready in 1234ms
```

> ⚠️ **このターミナルは閉じないでください。**
> 閉じるとアプリも止まります。
> アプリを止めたいときは `Control + C` を押します。

---

## ⑤ ブラウザで開く

**Chrome** や **Safari** などのブラウザを開いて、アドレスバーに以下を入力して `Enter`：

```
http://localhost:3000
```

**ログイン画面が表示されれば成功です。**

---

## ⑥ アカウントを作る

1. 画面下の「**新規登録**」をクリック
2. 以下を入力する：
   - **名前**：何でもOK（例：テスト太郎）
   - **メールアドレス**：何でもOK（例：test@example.com）
   - **パスワード**：6文字以上（例：password123）
3. 「**登録する**」ボタンをクリック
4. ToDo一覧の画面に移動すれば成功

---

## ⑦ ToDoを追加してみる

1. 右上または画面中央の「**+ 追加**」ボタンをクリック
2. タイトルに「**買い物に行く**」と入力
3. 「**追加**」ボタンをクリック
4. 「買い物に行く」がリストに表示されれば成功

---

## ⑧ 完了・編集・削除を試す

| 操作 | やり方 |
|---|---|
| **完了にする** | タスクの左端の **□** をクリック → 打ち消し線が入る |
| **編集する** | タスクにマウスを合わせる → 「**編集**」をクリック → 変更して「保存」|
| **削除する** | タスクにマウスを合わせる → 「**削除**」をクリック |

---

## ⑨ その他の機能を試す

| 機能 | 場所 | 操作 |
|---|---|---|
| **検索** | 画面上部の検索欄 | キーワードを入力するとリアルタイムで絞り込まれる |
| **フィルター** | 左サイドバー | 「未完了」「完了済み」などをクリックして絞り込む |
| **カテゴリ追加** | 左サイドバー「カテゴリ」横の **+** | カテゴリ名を入力して追加 |
| **ダークモード** | 右上の **☾** ボタン | クリックで画面が暗くなる |
| **カレンダー表示** | 左サイドバー「カレンダー」| 月次カレンダーに切り替わる |

---

## ⑩ ログアウトする

右上の「**ログアウト**」をクリック → ログイン画面に戻れば成功

---

# WBS管理アプリ

---

## ① ToDoアプリのサーバーを止める

WBSアプリも同じ 3000 番を使うため、先にToDoアプリを止めます。

ToDoアプリを起動しているターミナルで：

```
Control + C
```

> 両方同時に動かす方法は「よくある質問」を参照。

---

## ② 新しいターミナルを開く

`Command ⌘ + スペース` → `ターミナル` → `Enter`

---

## ③ wbs-app フォルダに移動する

```
cd ~/AI-test-Claude/wbs-app
```

---

## ④ 必要なファイルをインストールする（初回のみ）

```
npm install
```

---

## ⑤ アプリを起動する

```
npm run dev
```

```
▲ Next.js 16.x.x
- Local:   http://localhost:3000
```

---

## ⑥ ブラウザで開く

```
http://localhost:3000
```

ログイン画面が表示されれば成功。

---

## ⑦ アカウントを作る

1. 「**新規登録**」をクリック
2. 名前・メールアドレス・パスワードを入力
3. 「登録する」
4. ダッシュボード（ホーム画面）に移動すれば成功

---

## ⑧ プロジェクトを作る

WBSアプリでは「プロジェクト」の中に「タスク」を作ります。

1. 左サイドバーの「**プロジェクト**」をクリック
2. 右上の「**+ 新規**」をクリック
3. 以下を入力：
   - **プロジェクト名**：`テストプロジェクト`
   - **終了予定日**：1ヶ月後の日付
   - **ステータス**：進行中
4. 「**追加**」をクリック
5. 一覧に表示されれば成功

---

## ⑨ タスクを追加する

1. `テストプロジェクト` をクリックしてプロジェクト詳細画面へ
2. 「**+ タスク追加**」をクリック
3. 以下を入力：
   - **タスク名**：`要件定義`
   - **優先度**：高
   - **予定工数(h)**：8
4. 「**追加**」
5. WBSリストに `要件定義` が表示されれば成功

---

## ⑩ 子タスクを追加する（階層構造）

1. `要件定義` にマウスを合わせる
2. 右端に出る「**＋**」ボタンをクリック
3. タスク名：`画面設計`、予定工数：3 を入力して追加
4. `要件定義` の下に `画面設計` が表示されれば成功（WBSの階層構造）

---

## ⑪ タスクのステータスを変更する

1. タスクにマウスを合わせる
2. 「**編集**」をクリック
3. ステータスを「**進行中**」に変更 → 「保存」
4. バッジが青色の「進行中」に変われば成功

---

## ⑫ WBS表示とテーブル表示を切り替える

画面上部のボタンで表示を切り替えられます：

| ボタン | 表示内容 |
|---|---|
| **WBSリスト** | 階層ツリー（親子関係がわかる） |
| **テーブル** | 全タスクをフラットな表で表示 |

---

## ⑬ 今日のタスクに追加する

WBSのタスクを「今日やること」として登録できます。

1. プロジェクト詳細でタスクにマウスを合わせる
2. 右端の「**☑**」アイコンをクリック（薄く表示されている）
3. アイコンが黒くなれば登録完了
4. 左サイドバーの「**今日のタスク**」をクリック
5. 追加したタスクが表示されれば成功

---

## よくある質問

### Q. ToDoアプリとWBSアプリを同時に動かしたい

ターミナルを2つ開いて、それぞれ以下を実行します。

**ターミナル1（ToDoアプリ）:**
```
cd ~/AI-test-Claude/todo-app
npm run dev
```
→ ブラウザで http://localhost:3000 を開く

**ターミナル2（WBSアプリ）:**
```
cd ~/AI-test-Claude/wbs-app
npx next dev -p 3001
```
→ ブラウザで http://localhost:3001 を開く

---

### Q. アプリを止めたい

アプリが動いているターミナルで `Control + C` を押す。

---

### Q. データをリセットして最初からやり直したい

アプリを止めてから：

```
rm -rf ~/AI-test-Claude/todo-app/.data
rm -rf ~/AI-test-Claude/wbs-app/.data
```

次回起動時に自動で作り直されます。

---

### Q. ログインできない

- パスワードは6文字以上必要です
- メールアドレスの入力ミスがないか確認
- それでもダメなら上の「データをリセット」を試してください

---

### Q. ブラウザを開いても「このサイトにアクセスできません」と出る

ターミナルで `npm run dev` が動いているか確認してください。
止まっていたら再度 `npm run dev` を実行します。
