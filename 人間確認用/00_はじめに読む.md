# 👀 はじめに読む（人間が確認する用）

このフォルダは、**プログラムが分からない人でも、いま何があって・どう動くのかを
ひと目で確認できる**ようにまとめた資料です。

---

## このプロジェクトには何がある？

```
このリポジトリ
├── todo-app/        … ToDoリストアプリ（個人のやること管理）
├── wbs-app/         … WBS管理アプリ（プロジェクト管理）
├── インストーラー/   … 簡単インストール用ツール（Mac/Windows/iPhone）
├── supabase/        … クラウド公開・App Store用の設定と手順書
├── 人間確認用/       … ★このフォルダ（資料置き場）
└── 各種手順書.md     … セットアップ・起動の手順書
```

---

## 2つのアプリの違い（かんたんに）

| | 🗒 ToDoリスト | 📊 WBS管理 |
|---|---|---|
| 何をする？ | 「やること」をメモ・チェック | プロジェクトをタスクに分けて進捗管理 |
| 主な機能 | 追加/完了/検索/カテゴリ/カレンダー/通知 | プロジェクト/階層タスク/工数/進捗/今日のタスク |
| 向いている人 | 個人の日々のタスク管理 | チームや大きな作業の計画・管理 |
| 起動アドレス | http://localhost:3000 | http://localhost:3001 |

両方とも **白黒のシンプルなデザイン** で統一しています。

---

## ✨ 新しく追加した機能：クエストログ（ゲーム化）

両アプリの **画面左上** に「⚔ クエスト」という小さなボタンが出ます。
クリックすると、**今日やるべきタスクが「クエスト」として一覧表示**されます。

- ✅ クエストを完了するとチェックアニメ＋進捗バーが進む
- 🏆 全部終わると「全クエストクリア！」の達成演出
- 🔥 毎日続けると「連続達成日数（ストリーク）」が増える

ゲーム感覚でタスクをこなせる仕組みです。デザインは白黒で統一しています。
